# subcheck · ChatGPT 사용량 수집 실험

이 확장은 **자동 연동 가능성을 확인하기 위한 로컬 시제품**입니다. 제품용 실시간 동기화 기능이 아닙니다.

## 실제 확인한 사실

2026-10-27 ChatGPT `/settings/usage`의 화면에서 5시간·주간 한도의 남은 비율과 초기화까지 남은 시간을 확인했습니다. 이 영역은 Codex·Work 등의 **공유 한도**이며, 화면에 일반 Chat 대화는 포함되지 않는다고 명시되어 있습니다. 개인 GPT 채팅의 전체 잔여량으로 표시하면 안 됩니다.

## 실행

1. PC Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**에서 이 폴더를 선택합니다.
3. 확장 아이콘을 열고 **이 브라우저에서 수집 켜기**를 선택합니다.
4. 같은 Chrome의 로그인된 ChatGPT에서 `https://chatgpt.com/settings/usage`를 열거나 새로고침합니다.
5. 화면에 사용량 막대가 표시된 뒤 확장 아이콘을 다시 열어 비율과 수집 시각을 비교합니다.

설치 권한은 ChatGPT 사용량 설정 페이지와 확장 로컬 저장소로 제한했습니다. 쿠키·토큰·대화 수집, 네트워크 감청, 비공개 API 요청, 자동 페이지 방문, 외부 서버 전송은 하지 않습니다. 기본 수집은 꺼져 있습니다. 사용량 설정 경로 외에서는 수집을 중단합니다.

## 한계와 다음 판단

- 화면에서 확인한 두 공유 한도만 읽습니다. 일반 채팅·이미지·음성 등의 모든 한도를 수집하지 않습니다.
- 사용량 설정 페이지가 열려 있고 보이는 동안만 갱신합니다. 닫혀 있으면 오래된 값이므로 최신 잔액으로 취급할 수 없습니다.
- 초기화 시간은 화면의 상대 시간을 수집 시각에 더한 **추정값**입니다.
- DOM 구조나 언어가 달라지면 수집하지 않도록 실패합니다. 마지막 수치를 지어내지 않습니다.
- 실제 Chrome 확장 설치 후 수집은 아직 사용자 검증 전입니다. 현재 증거는 실제 화면의 DOM 가독성과 파서 검사입니다.
- Safari/iPhone 확장 배포, 휴대폰 동기화, 알림은 포함되지 않습니다.

이 실험이 성공해도 “평소 GPT 채팅만 쓰면 모든 사용량이 자동 동기화”가 입증되는 것은 아닙니다. 설정 화면을 따로 열어야 한다는 제약이 제품 가치를 만족하지 못한다면 이 방식은 보조 수단으로 한정해야 합니다.
