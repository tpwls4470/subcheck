# subcheck Chrome 수집 확장 · 0.3.1

설치·업데이트와 계정 연결 방법은 [이어가기 안내](../CONTINUE.md#chrome-확장-설치와-업데이트)를 참고하세요.

## 수집 범위

- ChatGPT `/settings/usage`: 화면에 표시된 Codex·Work 공유 5시간·주간 잔여율과 초기화 예상 시간. 일반 ChatGPT 대화 전체 한도가 아닙니다.
- Kling 멤버십의 구독 관리/Manage 창: 현재 플랜, 세금 포함 다음 청구금액과 Stripe 표시. 0.3.1은 한국어·영어 표시를 지원합니다.
- 요금표·소계·만료일을 실제 청구금액·결제일로 바꾸지 않습니다. 정확한 갱신일이 없으면 날짜는 비워둡니다.

수집과 동기화는 기본 꺼짐입니다. 사용자가 각각 켜야 합니다. 서비스 화면이 열리고 보이는 동안만 수집하며, DOM·표기가 달라지면 수집하지 않을 수 있습니다. 쿠키·토큰·대화를 읽거나 비공개 API와 네트워크 감청을 사용하지 않습니다.

동기화에 동의한 경우, 같은 Chrome의 로그인된 서브체크 연결 탭을 통해 지정된 서브체크 사이트에 필요한 수치만 전송합니다. 서버는 계정·출처·CSRF·값 범위를 검사합니다. 클링 결제정보는 확인 대기 기록으로 저장되고, 사용자가 앱에서 적용 후 별도 저장합니다.

## 확인된 결과

2026-10-27 사용자 Chrome에서 ChatGPT 사용량 수집·계정 동기화와 클링 한국어 결제정보 수집·동기화를 확인했습니다. 최종 구독 저장 완료는 별도 확인이 남아 있습니다. iPhone Safari 확장판은 제공하지 않습니다. 같은 계정의 온라인 웹앱에서는 PC가 동기화한 기록을 볼 수 있습니다.
