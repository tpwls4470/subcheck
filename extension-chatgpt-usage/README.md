# subcheck Chrome 수집 확장 · 0.5.1

## 0.5.1 안정화

동시 요청의 탭 중복 생성, 지연된 탭 생성의 제한 시간 처리, 소스 탭 닫힘·동의 철회 시 중단을 보완했습니다. 최근 새로고침 상태와 마지막 조회 성공 시각을 기록하고, 서비스 워커 재시작으로 중단된 조회를 성공으로 표시하지 않습니다. 네트워크 요청에는 12초 제한을 적용했습니다. 이전 저장값이나 성공 시각을 실패 때문에 지우지 않습니다.

추가 권한은 없습니다. 검사 21개를 통과했으며 실제 Chrome의 반복 조회·재시작 후 재연결 확인은 남아 있습니다. 기존 계정을 강제로 로그아웃하거나 브라우저를 종료해 시험하지 않았습니다. 업데이트 후 서브체크 탭도 새로고침하세요.

## 0.5.0 사용자 요청에 의한 백그라운드 조회 실험

2026-10-29 사용자 새로고침 후 앱의 조회 성공·자동 반영 안내와 서버 기록의 수집/반영 시각 갱신을 실제 확인했습니다. 이번 사용자 환경에서 성공한 결과이며 장기 로그인 유지나 모든 기기에서의 동작을 보장하지 않습니다.

같은 Chrome의 서브체크 화면 새로고침 버튼을 실제 누르면 확장이 클링 멤버십 페이지를 비활성 탭으로 잠깐 열어 구독 관리/Manage 창의 다음 청구금액·플랜을 읽습니다. 기존 billingEnabled 동의가 필요합니다. 기존 탭은 건드리지 않고 확장이 만든 탭만 정리합니다. 로그인·추가 인증이 필요하면 멈추고 안내하며 생성·구매·해지·업그레이드는 실행하지 않습니다.

소계·세금 합계가 최종 청구금액과 일치하고 안정화된 후 전송합니다. 앱의 자동 업데이트 설정이 켜져 있으면 해당 계정의 내 구독에 반영됩니다. 전체 조회는 45초로 제한하고 실패 시 기존 저장값을 유지합니다. 사용자가 활성화한 조회 탭은 닫지 않습니다. 확장/브라우저 강제 종료 시 탭이 남을 수 있습니다. 추가 권한은 없습니다.

설치 업데이트 후 서브체크 탭도 새로고침하세요. 클링 탭을 닫아둔 상태에서 서브체크 새로고침 한 번으로 조회되는지 실제 Chrome 검증이 남아 있습니다. 제어된 코드 검사를 통과한 실험이며, 클링 측의 비활성 탭 로딩·언어·화면 변경에 따라 실패할 수 있습니다. 휴대폰 단독 조회는 제공하지 않습니다.

구현 근거: [Chrome Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs), [메시지 전달](https://developer.chrome.com/docs/extensions/develop/concepts/messaging), [서비스 워커 수명](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle). 진행 중인 조회에서만 제한된 확인 메시지를 보내며 상시 실행하지 않습니다.

0.4.1은 서버가 이 기록을 내 구독에 자동 반영했는지 응답으로 확인해 팝업에 표시합니다. 자동 반영은 서브체크에서 사용자가 서비스별로 켠 경우에만 이루어집니다. 새 권한은 추가하지 않았습니다. 코드 검사는 통과했으며 실제 Chrome의 0.4.1 업데이트 후 갱신 검증은 별도로 필요합니다.

## 0.4.0 동기화 진단

팝업 위쪽에 클링 화면 읽기, 서버 전송, 앱 반영 단계를 표시합니다. 마지막 수집 시각과 마지막 전송 성공 시각은 별도 표시하며 실패해도 이전 성공 시각은 지우지 않습니다. 서버 전송 성공만으로 실제 구독 반영이 끝났다고 표시하지 않습니다.

닫힌 연결 탭, 아직 확장 코드가 연결되지 않은 탭, 로그인 필요, 보안 확인 거절, 유효하지 않은 기록, 통신 실패와 서버 오류를 구분합니다. ‘전송 다시 시도’는 이미 읽은 최신 기록만 다시 보내며 클링을 자동 방문하거나 오래된 기록의 수집 시각을 바꾸지 않습니다. 하루가 지난 기록은 전송하지 않습니다. 새 권한은 추가하지 않았습니다.

업데이트 후 Chrome 확장 관리에서 새로고침하고 팝업 버전 0.4.0을 확인하세요. 클링과 서브체크 탭도 새로고침해야 기존에 주입된 코드가 교체됩니다. 코드 검사와 오류 응답 검증은 통과했으며 실제 Chrome에서의 업데이트 후 재수집·진단 표시 확인은 별도로 필요합니다.

설치·업데이트와 계정 연결 방법은 [이어가기 안내](../CONTINUE.md#chrome-확장-설치와-업데이트)를 참고하세요.

## 수집 범위

- ChatGPT `/settings/usage`: 화면에 표시된 Codex·Work 공유 5시간·주간 잔여율과 초기화 예상 시간. 일반 ChatGPT 대화 전체 한도가 아닙니다.
- Kling 멤버십의 구독 관리/Manage 창: 현재 플랜, 세금 포함 다음 청구금액과 Stripe 표시. 0.3.1은 한국어·영어 표시를 지원합니다.
- 요금표·소계·만료일을 실제 청구금액·결제일로 바꾸지 않습니다. 정확한 갱신일이 없으면 날짜는 비워둡니다.

수집과 동기화는 기본 꺼짐입니다. 사용자가 각각 켜야 합니다. 일반 자동 수집은 서비스 화면이 열리고 보이는 동안만 수행합니다. 0.5.0의 명시적 새로고침 요청에 한해 확장이 생성한 클링 탭에서 제한된 시간 동안 숨김 상태의 DOM을 읽습니다. DOM·표기가 달라지면 수집하지 않을 수 있습니다. 쿠키·토큰·대화를 읽거나 비공개 API와 네트워크 감청을 사용하지 않습니다.

동기화에 동의한 경우, 같은 Chrome의 로그인된 서브체크 연결 탭을 통해 지정된 서브체크 사이트에 필요한 수치만 전송합니다. 서버는 계정·출처·CSRF·값 범위를 검사합니다. 클링 결제정보는 확인 대기 기록으로 저장되고, 사용자가 앱에서 적용 후 별도 저장합니다.

## 확인된 결과

2026-10-27 사용자 Chrome에서 ChatGPT 사용량 수집·계정 동기화와 클링 한국어 결제정보 수집·동기화를 확인했습니다. 2026-10-29 에이전트가 현재 서비스 화면을 직접 확인한 정보를 구독 폼에 저장하고 상세 화면에서 검증했습니다. 확장 새 기록에 의한 자동 반영 검증은 남아 있습니다. iPhone Safari 확장판은 제공하지 않습니다. 같은 계정의 온라인 웹앱에서는 PC가 동기화한 기록을 볼 수 있습니다.
