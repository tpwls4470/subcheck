# subcheck

구독 결제 일정과 개인 사용량을 한눈에 확인하는 웹앱의 로컬 개발 버전입니다.

## 현재 기능

- 내 구독 / 내 사용량 / 마이페이지 및 밝은 색상 선택
- 로고 클릭 시 내 구독으로 이동. 결제 예정일·금액·주기·플랜·관리 안내를 내 구독에 모으고, 내 사용량은 남은 혜택에 집중
- Kling 공식 별도 로그인, 개인 유료 크레딧과 플랜 조회 및 새로고침
- Pro 월 3,000크레딧 대비 현재 잔액의 참고 비율
- 결제 일정 및 다른 서비스는 **예시 데이터**로 표시

## 실행

Node.js 22 이상이 필요합니다. 별도 npm 라이브러리 설치는 필요하지 않습니다. 글꼴과 아이콘은 CDN을 사용합니다.

1. npm run build
2. 최초 한 번 npm run auth:register — 클링에 공개 테스트 클라이언트를 등록합니다. 콜백 주소는 http://127.0.0.1:4319/oauth/callback 입니다.
3. 첫 터미널에서 npm run auth:start
4. 두 번째 터미널에서 npm start
5. http://127.0.0.1:4320/ 에서 클링 연결을 시작하고 공식 화면에서 승인합니다. 승인 후 자동으로 앱에 돌아옵니다.

마이페이지 → 연결한 서비스에서 ‘이 기기에서 연결 해제’를 선택하면 확인 후 이 서버 세션의 연결 정보와 잔액을 삭제합니다. 클링 구독 해지나 클링 계정에 승인한 권한 취소는 수행하지 않습니다.

인증 서버와 앱 서버는 같은 컴퓨터에서 실행합니다. 토큰은 인증 서버 메모리에만 있으며 재시작하면 다시 연결해야 합니다. 생성·구매 기능은 구현하지 않았습니다. 공개 클라이언트 설정도 저장소에는 포함하지 않습니다.

## 비율의 의미

[클링 공식 가이드](https://kling.ai/blog/kling-video-3-0-credit-cost-guide?tab=all)의 Pro 월 3,000크레딧을 기준으로 현재 조회 잔액 ÷ 3,000 × 100을 표시합니다(확인일 2026-10-26).

추가 구매분 등이 섞일 수 있어 **이번 달 구독 크레딧의 정확한 잔여율이 아닙니다.** 100% 초과 시 숫자는 그대로 표시하고 원형 도형만 한 바퀴로 제한합니다. 다른 플랜의 기준은 임의 추정하지 않습니다. 보너스·팀 크레딧은 조회 지원 범위 밖이며 초기화·만료일은 현재 응답에 없습니다.

## 검증

npm test는 비율 계산, 0잔액, 미확인 플랜, 100% 초과 및 인증 조회 응답의 기본 처리를 검사합니다. 실제 외부 로그인 성공은 사용자 동의가 필요한 별도 수동 검증입니다.

## 아직 개발 중

공개 배포, 다중 사용자 저장, 회원 로그인, 실제 알림 발송, 서비스 측 권한 취소 및 토큰 갱신은 미완료입니다. 자동 복귀는 코드와 경로 검사를 완료했으며 실제 재로그인 검증은 별도입니다. 로컬 서버를 그대로 공용 서버로 노출하지 마세요. GitHub에 코드를 올리는 것은 웹앱 배포와 별개입니다.

## 서비스 이미지와 저장 UI

49개 서비스의 아이콘 이미지를 assets/service-logos에 보관하고 출처를 기록했습니다. 구독 예시는 접힌 목록에서 선택한 서비스만 보여줍니다. 로그인·회원가입 버튼의 텍스트와 화살표는 한 줄 중앙 정렬입니다. 실제 구독 저장은 online 버전의 DB 바인딩이 필요하며 로컬 단순 미리보기 서버에는 연결되지 않습니다.

## 결제 알림
구독별 3일 전·당일 설정은 D1에 저장합니다. 기본 시간은 한국 오전 9시입니다. 캘린더 내보내기는 명시적 일정이며 자동 동기화되지 않습니다. 웹 푸시는 VAPID로 빈 메시지를 보내고 기기에서 일반 안내를 표시합니다. 개인 결제 정보는 푸시 서버로 보내지 않습니다. 일일 발송은 Sites 연결 도구 send_due_payment_reminders와 연결된 예약 실행을 사용합니다. 실제 수신은 브라우저 알림 허용 및 기기 연결 후 확인해야 합니다.

클링 Pro 사용량 알림: 월 지급량 3,000 대비 10/20/30% 임계값. 기본 꺼짐. 공식 잔액 새로고침 성공 시 서버에서 검사하며 동일 부족 상태에는 한 번만 푸시합니다. 기준 위로 회복되면 다시 활성화됩니다. 앱을 닫은 동안의 잔액 자동 감시 기능은 아닙니다.
