# subcheck

구독 결제 일정과 남은 사용량을 한곳에서 확인하는 웹앱입니다. 현재 본인 전용 온라인 테스트를 진행하고 있습니다.

## 현재 기능

- 내 구독: 서비스·플랜·결제일·금액 저장, 달러 금액과 원화 예상액, 결제 알림 설정.
- 내 사용량: 공식 클링 개인 유료 크레딧 조회, PC 확장으로 수집한 ChatGPT Codex·Work 공유 사용량 표시.
- 클링 결제정보: PC 확장에서 한국어·영어 구독 관리 창의 플랜과 다음 청구금액을 읽고, 서비스별 자동 업데이트를 켜면 새 기록을 내 구독에 반영. 직접 입력한 결제일·알림 설정은 유지.
- 확장 0.5.0 실험: PC Chrome의 서브체크 새로고침으로 클링을 비활성 탭에서 조회하고 결과 표시. 코드 검사는 통과했으며 닫힌 클링 상태에서 실제 Chrome 검증은 진행 중.
- 마이페이지: 계정·연결·알림·기기 상태 확인. 모바일 홈 화면 앱과 웹 푸시, 캘린더 일정 파일 내보내기.
- 서비스 로고 검색·분류, 간편 날짜 달력, 다양한 결제 수단, 고정 하단 메뉴.

모르는 정보는 비워둡니다. 클링 만료일을 결제일로 바꾸거나, 일반 ChatGPT 채팅의 잔여량을 추정하지 않습니다. 화면 예시와 실제 연결·저장한 정보를 구분합니다.

## 코드와 빌드

Node.js 22 이상을 사용합니다.

```sh
npm run build
npm test
node --test extension-chatgpt-usage/test/*.test.mjs
npm --prefix online test
npm run build:online
```

`src`는 화면 원본, `online`은 호스팅 서버·DB·알림 원본, `extension-chatgpt-usage`는 Chrome 확장입니다. 루트 `npm start`는 이전 로컬 인증 실험 서버이므로 온라인 계정·DB 저장을 그대로 재현하지 않습니다. 로컬 실험을 사용할 때는 `npm run auth:register`, `npm run auth:start`로 같은 PC의 인증 서버를 별도로 준비해야 합니다.

## 범위와 남은 확인

클링 Pro 월 3,000크레딧 대비 잔액 비율은 추가 구매분 등이 포함될 수 있는 참고치입니다. ChatGPT 수집은 사용량 설정 화면의 Codex·Work 공유 한도이며 일반 채팅 전체 한도가 아닙니다. ChatGPT 사용량 화면을 닫으면 해당 수집은 갱신되지 않습니다. 클링 결제정보의 백그라운드 조회는 PC Chrome에서 사용자가 요청할 때만 수행하는 별도 실험입니다.

사용자 기기의 테스트 푸시 수신과 확장 수집·계정 동기화가 확인됐습니다. 실제 결제일의 예약 알림 수신, 클링 정보 최종 저장 결과, 장기 연결 유지, 다른 서비스 연동은 추가 확인이 필요합니다. 캘린더는 일정 파일 내보내기이며 실시간 동기화가 아닙니다. 클링 사용량 알림은 잔액 새로고침 시 검사하며 앱을 닫은 동안 잔액을 자동 감시하지 않습니다.
