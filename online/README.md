# subcheck online

본인 전용 Sites 웹앱. 클링의 별도 공식 OAuth를 통해 개인 유료 크레딧을 조회합니다. 사이트 ChatGPT 로그인과 클링 연결 동의는 별개입니다.

클링 토큰과 인증 대기 정보는 AES-GCM으로 암호화된 Secure/HttpOnly/SameSite 쿠키에 기기별로 보관합니다. 암호화 키는 Sites 런타임 비밀 값이며 GitHub나 브라우저 코드에 포함하지 않습니다. 복호화는 사이트 사용자 ID에 결합되어 다른 사용자에게 쿠키를 옮겨 사용할 수 없습니다. 온라인 상태와 정상 조회 결과만 UI로 전달합니다. 별도 데이터베이스는 사용하지 않습니다.

지원 범위: 공식 로그인, 자동 복귀, 플랜·개인 유료 크레딧 조회, 새로고침, 만료 시 토큰 갱신 시도, 연결 해제 시 토큰 폐기 요청과 기기 쿠키 삭제. 생성 기능은 호출하지 않습니다. 보너스·팀 크레딧은 포함하지 않으며 월 지급량 대비 비율은 참고치입니다.

환경 변수: KLING_CLIENT_ID, SUBCHECK_SEAL_KEY(비밀 값). 외부 앱 등록 콜백은 사이트의 /oauth/kling/callback 입니다. 빌드: npm run build. 검사: npm test.

아직 실증하지 않은 항목은 실제 클링 계정의 온라인 로그인·잔액·갱신·폐기 결과이며, 배포 후 사용자 승인으로 확인합니다. 실제 결제 일정·알림·다른 서비스는 연결되지 않았습니다.

## 검증 상태

본인 전용 배포 주소에서 별도 공식 로그인, 온라인 실제 잔액·플랜 조회, 새로고침, 페이지 재진입 시 연결 유지가 확인됐습니다. 외부 요청의 리디렉션은 manual로 제한합니다. 만료 갱신과 실제 토큰 폐기는 시험 응답으로 검사했으며 실제 계정의 만료·폐기 결과 검증은 남아 있습니다.

## 구독 정보 저장

D1의 DB 바인딩과 drizzle 마이그레이션을 사용합니다. 사용자 ID는 사이트 로그인에서만 읽으며, 저장·수정·목록 조회는 사용자별로 제한합니다. 예시 목록은 자동 저장하지 않습니다. 선택한 서비스에 대해 사용자가 확인한 플랜·결제금액·날짜를 입력해 저장합니다. 모르는 정보는 비워둘 수 있고 크레딧은 수동 입력하지 않습니다. 데이터베이스 구조 생성은 npm run db:generate를 사용합니다.
